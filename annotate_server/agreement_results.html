Calculation and source details
Each record matches by original conversation ID and turn. C-numbers use the shared mapping across methods. WN records follows the WN file's record order; All annotators' records includes the union of their keys. Pairwise scoring includes only records with an explicit E-label set or No failure from both people. EX, IE, OT, missing decisions, and unsupported or conflicting labels are omitted from that pair. NF is a valid all-zero E-label decision. Review marks alone do not count as labels.

Agreement is the fraction of matching yes/no decisions for an E. Cohen's κ = (observed agreement - expected agreement) / (1 - expected agreement). N/A means no eligible records or constant agreeing decisions with undefined κ. Frequency weights count turns where either person selected the E; undefined kappas are omitted from the weighted mean. Thresholds use full precision. Three-person summaries use all records in the selected sample, including missing and special decisions. Exported results reads Annotate_result; Live server saves reads each run's annotations folder. Sources are never mixed.
